**Declared weights: 2 (400 regular, 600 semibold). No other weights permitted in this phase.**

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / table cell | 14px (`text-sm`) | 400 (regular) | 1.5 |
| Label / column header | 14px (`text-sm`) | 600 (semibold) | 1.5 |

- App title: use `font-semibold` (600) instead of `font-bold` (700). No visible regression at 20px.

- Do not introduce `font-medium` (500) or `font-bold` (700) anywhere in this phase.

## Toolbar Interaction Contract

### "‹ Prev week" button
- **Label:** `‹ Prev week` (literal, not localised — Finnish parents are accustomed to week navigation)
  - Source: D-06 in CONTEXT.md
- **Action:** Subtracts 7 days from current `viewStart`, calls `router.replace('?viewStart=YYYY-MM-DD')`.
- **Monday snapping:** `viewStart` is always snapped to Monday of that week (round down to startOfWeek with `date-fns` `fi` locale).
- **Always enabled:** No disabled state — no backward limit per D-10.
- **Loading state:** Next.js `loading.tsx` skeleton (or Suspense boundary) renders during server re-render. The toolbar itself remains visible; the schedule table below shows a skeleton.

### "Pick date 📅" button (DatePicker)
- **Label:** `Pick date` with calendar emoji, or Finnish: `Valitse päivä` — use Finnish to match app language: **`Valitse päivä`**
- **Action:** Opens shadcn Popover containing a Calendar component. Selected date snaps to Monday of that week (`startOfWeek` with `{ weekStartsOn: 1 }` from `date-fns`). On select, calls `router.replace('?viewStart=YYYY-MM-DD')`.
- **Popover placement:** Below trigger, left-aligned.
- **Calendar locale:** `fi` locale from `date-fns` — Monday as first day of week.

### "Tänään" button
- **Label:** `Tänään` (Finnish for "Today") — matches existing button label per D-07.
- **Action (two steps):**
  1. Calls `router.replace('/dashboard')` (clears `viewStart` param — resets to Mon of current week) per D-08.
  2. After navigation settles, calls `document.querySelector('[data-today="true"]')?.scrollIntoView({ behavior: "smooth", block: "center" })` — reusing existing scroll logic from `today-button.tsx`.
- **Variant:** `default` (filled, near-black) — primary accent, visually distinct from the outline buttons.

## States

| State | Component | Visual Treatment |
|-------|-----------|-----------------|
| Default view (no `viewStart` param) | Toolbar | Tänään button filled; Prev week and Valitse päivä are outline |
| View start in the past | Toolbar | All three buttons are rendered. Tänään button invites reset. |
| Loading (URL changed, server re-rendering) | Schedule table | `loading.tsx` or Suspense fallback — skeleton rows. Toolbar stays mounted. |
| DatePicker open | Popover | Overlay popover with Calendar. Rest of UI remains interactive. |
| DatePicker date selected | Popover + page | Popover closes. `router.replace` fires. Loading state begins. |

## Accessibility Contract

- All toolbar buttons have accessible labels (text is visible — no icon-only buttons in this phase).
- `‹` arrow character is decorative; screen readers read the full label `‹ Prev week` / `Prev week` is sufficient.
- DatePicker Calendar uses shadcn/calendar built-in `aria-label` for day cells (provided by react-day-picker).
- Keyboard navigation: Tab through toolbar left-to-right, Enter/Space activate. Popover traps focus when open (Radix/Base UI default).
- Touch targets: `size="sm"` buttons are `h-7` (28px). On mobile, toolbar may need additional padding — acceptable for v1.1 (mobile refinement deferred to ONBR-02).
