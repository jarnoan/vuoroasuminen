# Requirements Archive — v1.2 Supabase Auth Migration

**Archived:** 2026-05-15
**Status:** All requirements complete

## v1.2 Requirements (Final Status)

### Supabase Auth (SAUTH)

- [x] **SAUTH-01**: User can sign in with Google via Supabase OAuth flow (PKCE) — Phase 8 ✓
- [x] **SAUTH-02**: User session persists across page refreshes via Supabase cookie-based session — Phase 8 ✓
- [x] **SAUTH-03**: User can sign out — Phase 8 ✓
- [x] **SAUTH-04**: Unauthenticated users are redirected to sign-in when accessing protected routes — Phase 8 ✓
- [x] **SAUTH-05**: Sign-in always forces `access_type:offline` + `prompt:consent` so Google re-issues a refresh token on every sign-in — Phase 8 ✓
- [x] **SAUTH-06**: Google refresh token is captured from the OAuth callback and stored in `user_google_tokens` table — Phase 8 ✓
- [x] **SAUTH-07**: Dashboard shows a dismissible warning when the calendar owner's token row is absent — Phase 8 ✓

### GCal Owner Model (GCAL)

- [x] **GCAL-01**: GCal sync uses `ownerEmail` from calendar config to look up credentials, regardless of which parent triggers publish — Phase 8 ✓
- [x] **GCAL-02**: `app.ts` calendar config includes an `ownerEmail` field per calendar entry — Phase 8 ✓

### Row Level Security (RLS)

- [x] **RLS-01**: RLS enabled on all domain tables — unauthenticated requests return no data — Phase 9 ✓
- [x] **RLS-02**: Any authenticated user can read and write all rows on domain tables — Phase 9 ✓
- [x] **RLS-03**: Each user can read and write only their own row in `user_google_tokens` — Phase 9 ✓ (policy confirmed via pg_policies; Dashboard impersonation test deferred — requires Pro plan)
- [x] **RLS-04**: Supabase Realtime subscription uses authenticated Supabase JWT — Phase 9 ✓ (JWT race condition fixed)

### Auth.js Cleanup (CLEAN)

- [x] **CLEAN-01**: `next-auth` and `@auth/drizzle-adapter` packages uninstalled — Phase 10 ✓
- [x] **CLEAN-02**: Auth.js database tables dropped via safe migration (FK order: verificationTokens → sessions → accounts → users) — Phase 10 ✓
- [x] **CLEAN-03**: Auth.js environment variables removed; Google OAuth vars renamed to GOOGLE_CLIENT_* — Phase 10 ✓
