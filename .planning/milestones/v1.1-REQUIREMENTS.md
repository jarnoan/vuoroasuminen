## v1.1 Requirements (Final Status)

### View Window

- [x] **VIEW-01**: View window starts from Monday of the current week by default — past days of the current week are visible — **VALIDATED v1.1**
- [x] **VIEW-02**: User can tap/click "Show previous week" to extend the view one week back; action is repeatable — **VALIDATED v1.1**
- [x] **VIEW-03**: User can set an explicit start date for the view via a date picker — **VALIDATED v1.1**
- [x] **VIEW-04**: View window preferences (start date) are stored per-user — one parent's changes do not affect the other's view — **VALIDATED v1.1**

### Extend Schedule

- [x] **EXTEND-01**: User can extend the schedule forward by N weeks (default 12); new entries are pre-filled with the alternating-week default pattern — **VALIDATED v1.1**
- [x] **EXTEND-02**: Before confirming, the UI shows the start and end dates of the range being added — **VALIDATED v1.1**
- [x] **EXTEND-03**: User can specify an explicit end date instead of adding a fixed number of weeks — **VALIDATED v1.1**

### Clear Entries

- [x] **CLEAR-01**: User can clear a single cell — the child's assignment on that day becomes unassigned (empty, no parent) — **VALIDATED v1.1**
- [x] **CLEAR-02**: User can select a date range and clear all child assignments within it — all cells in range become unassigned — **VALIDATED v1.1**
