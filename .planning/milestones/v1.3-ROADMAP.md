**Status:** ✅ SHIPPED 2026-05-17

## Milestone Summary

**Key Decisions:**

- Invite token stored in DB with expiry — not signed JWT alone; DB storage enables revocation
- Three-tier middleware gate: auth → setup completeness → email membership (unauthorized emails signed out gracefully)
- familyConfig table replaces all APP_PARENT* env vars; getAppConfig() reads from DB at runtime
- `generate-app-config.js` updated to exit 1 on missing env vars (build-time safety net)
- Vercel production env vars set via `vercel env add` (interactive — values never in shell history)
- DATABASE_URL on Vercel uses pooler port 6543 with `?pgbouncer=true` (local uses 5432)

**Issues Resolved:**

- Phase 11: Next.js 16 build failure due to middleware.ts naming convention (renamed to proxy.ts)
- Phase 12: Hardcoded APP_PARENT* env var pattern blocked self-service onboarding (replaced with DB)
- Phase 13 CR-01: invite token delete+insert wrapped in transaction to prevent race condition
- Phase 13 CR-02: conditional Secure flag on invite_token cookie (http in dev, https in prod)
- Phase 13 WR-02: navigator.clipboard calls wrapped in try/catch for non-HTTPS contexts
- Phase 13 WR-03: signOut() called before building errorRedirect in proxy to clear session properly
