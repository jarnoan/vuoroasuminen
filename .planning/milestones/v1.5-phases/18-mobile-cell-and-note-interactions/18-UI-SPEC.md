**UI-04 transition color contract:**

## Interaction Contract

This section is specific to Phase 18 and describes the three interaction patterns implemented.

### UI-03: Pen Icon (note affordance button)

- **Element:** The `<button>` in the mobile-only `<td>` at schedule-table.tsx ~line 344
- **Change:** Replace `<PlusIcon className="h-4 w-4" />` with `<PencilIcon className="h-4 w-4" />`
- **Icon choice:** `PencilIcon` from lucide-react — the standard lucide pencil glyph, named `Pencil`. Avoid `Pen` (too minimal) and `PenLine` (adds stroke detail not needed at h-4 w-4). Source: Claude's discretion per CONTEXT.md.
- **Size:** `h-4 w-4` (16×16px) — unchanged from PlusIcon
- **Color:** `text-muted-foreground hover:text-foreground` — unchanged
- **aria-label:** `Lisää muistiinpano — {dayLabel}` — unchanged
- **touchAction:** `manipulation` — unchanged
- **Viewport:** Mobile only — `max-sm:table-cell sm:hidden` wrapping td is unchanged

### UI-04: Tyhjennä Full-Cell (long-press armed state)

**State machine:**

| State | Trigger | Visual | Text |
|-------|---------|--------|------|
| idle | — | parent color (blue/rose per status) | parent name |
| holding | pointerdown held | parent color → destructive fade over 1000ms CSS transition | parent name (unchanged during fade) |
| armed | 1000ms timer fires | `bg-destructive text-white` (instant snap — transition class removed after fire) | "Tyhjennä" |
| cleared | tap on armed cell | cell unmounts (cleared from state) | — |
| disarmed | pointerup before 1s, or 2000ms auto-disarm | snap to parent color instantly (no reverse fade) | parent name |

**Media query split:**
- `@media (hover: none)`: full-cell Tyhjennä interaction (phones + tablets)
- `@media (hover: hover)`: existing corner `×` button on hover (mouse/trackpad)
- Implementation: Use Tailwind's `[@media(hover:none)]:` and `[@media(hover:hover)]:` variants to conditionally show/hide the two clear affordances. The `isArmed` state and timer machinery are shared.

**Holding state implementation:**
- Add `isHolding` boolean state (separate from `isArmed` — simpler than a class ref)
- On `pointerdown`: set `isHolding = true`, start armTimer
- On arm fires (1000ms): set `isHolding = false`, set `isArmed = true`, call `navigator.vibrate(100)`
- On cancel: set `isHolding = false` instantly (removes transition class = instant color snap)
- CSS: when `isHolding`, add `transition-colors duration-1000` class AND set destination color class `bg-destructive`; when not holding, remove both

**Vibration:** `navigator.vibrate(100)` — single 100ms pulse, fires exactly when `isArmed` becomes true. No vibration during the hold/fade. Source: REQUIREMENTS.md UI-04, CONTEXT.md D-08.

**Tyhjennä button (armed state):**
- Fills the entire cell: `w-full h-full` (no rounded corners, no absolute positioning)
- Background: `bg-destructive`
- Text: `text-white text-sm font-medium` — "Tyhjennä"
- On click: calls `onClear(entryId)`, sets `isArmed = false`, clears disarmTimer
- No sub-target: tapping anywhere on the red cell clears it. Source: CONTEXT.md D-03.

**Desktop/hover unchanged:** The existing corner `×` button (`absolute top-0.5 right-0.5`) remains for `@media (hover: hover)` devices. Source: ROADMAP.md Phase 18 SC-4, CONTEXT.md D-04.

### UI-05: Note Row Attribution

**Visual contract:**
- Zero top gap on note `<tr>`: remove `py-1` top from the note row's `<td>`, use `pb-1 pt-0` instead
- Left indent: `pl-8` (32px) on the note row `<td>` content — the `colSpan` td gets `pl-8` instead of `px-1`, so the NotesCell input appears indented under the date column's text offset
- Day row border: When `day.notes || notesOpenDates.has(day.date)` is true, the day `<tr>` removes its bottom border. Add a conditional class: `[&:has(+tr)]:border-b-0` or explicit conditional Tailwind class on the day row. The dividing line appears only after the note row, not between day row and note row.
- The note `<tr>` gets its own bottom border so the visual unit (day row + note row) is separated from the next day.

Source: CONTEXT.md D-09, D-10, D-11 (locked decisions).
