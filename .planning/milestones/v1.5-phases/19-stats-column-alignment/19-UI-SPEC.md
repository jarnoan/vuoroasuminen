## Layout Alignment Contract

This section is the primary design contract for Phase 19 (UI-06). It specifies the exact column-width relationship between ScheduleTable and StatsPanel.

### Problem Statement

StatsPanel renders an independent `<table>` below ScheduleTable. Its column widths are content-driven and unrelated to ScheduleTable column widths. The requirement (UI-06) is that each child column in StatsPanel aligns visually with the same child column in ScheduleTable above it, at all viewport widths.

### Column Structure

ScheduleTable column order:
1. Date column — sticky left, `px-3 py-2`, content-driven width, `whitespace-nowrap`
2. Child columns (N children) — `min-w-[72px]` mobile / `min-w-[90px]` desktop
3. Notes column — `min-w-[160px]`, hidden on mobile (`max-sm:hidden`)

StatsPanel column order:
1. Parent name label column — must match date column width
2. Child columns (N children) — must match child columns width

Note: StatsPanel has no column corresponding to Notes. The label column in StatsPanel (parent name) aligns with the date column in ScheduleTable.

### Alignment Approach

The alignment must be achieved via CSS only — no shared JavaScript state for column widths. The approach is:

**Use `table-layout: fixed` on StatsPanel's `<table>` with explicit column widths matching ScheduleTable.**

Concretely:
- Wrap both ScheduleTable and StatsPanel in a shared container that establishes the same horizontal width.
- Add `<colgroup>` / `<col>` elements to StatsPanel's `<table>` that declare widths matching ScheduleTable's column classes.
- Apply `table-layout: fixed` to StatsPanel's table so declared widths are honored.
- The date/label column: use the same padding class (`px-3`) on StatsPanel's label `<td>` as ScheduleTable's date `<td>`.
- The child columns: apply `min-w-[72px] sm:min-w-[90px]` to StatsPanel child `<th>` and `<td>` elements, identical to ScheduleTable.

### Responsive Behavior

| Viewport | Date column | Child columns | Notes column |
|----------|-------------|---------------|--------------|
| Mobile (< sm) | Content-driven, sticky left | min-w-[72px] | Hidden |
| Desktop (sm+) | Content-driven, sticky left | min-w-[90px] | Present (stats has no notes column — no change needed) |

StatsPanel must replicate ONLY the date column and child columns. The notes column is absent from StatsPanel and needs no handling.

### Exact Classes to Replicate in StatsPanel

Label column `<th>` / `<td>` (currently blank `<th />`):
- Before: no width constraint
- After: `px-3 py-1` — matches ScheduleTable date column horizontal padding

Child column `<th>` / `<td>`:
- Before: `px-2`
- After: `px-1 min-w-[72px] sm:min-w-[90px]` — matches ScheduleTable child column

Table element:
- Add `table-layout-fixed` equivalent: `[table-layout:fixed]` Tailwind arbitrary property, or native `style={{ tableLayout: "fixed" }}` on the `<table>`.

### Success Criteria Verification

SC-1: Each child column in StatsPanel is the same width as the corresponding child column in ScheduleTable above it — verified by visual alignment in browser dev tools.
SC-2: Columns visually align when both elements are on screen simultaneously.
SC-3: Alignment holds at 360px (mobile) and 1280px (desktop) viewport widths.
