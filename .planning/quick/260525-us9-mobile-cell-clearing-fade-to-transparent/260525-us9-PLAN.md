New behavior (coarse pointer / mobile):

1. pointerdown: start a 2-second timer (armTimerRef), set isHolding=true, record startX/startY.
2. During the hold, the cell fades from its normal opacity to 0 using a CSS transition on opacity. Use inline style: `opacity: isHolding ? 0 : 1` with a `transition: opacity 2s linear` applied only when isHolding=true. 4. pointerup / pointercancel / move > 8px: cancel the timer, reset isHolding=false (cell snaps back to full opacity).
5. onClick: when NOT holding and NOT armed, toggle as usual (onToggle). Remove the isArmed branch from onClick entirely.

Remove "Tyhjennä" text from the coarse-pointer span (currently: `{isArmed ? "Tyhjennä" : displayName}`). Replace with just `{displayName}` always — the hold gesture is the affordance, no label needed.

Remove isArmed and disarmTimerRef state declarations and all code paths that reference them.

The desktop × button (pointer:fine only) is unchanged — keep it exactly as is.

Implementation notes:
- Use a single `armTimerRef` (rename from armTimerRef if desired, or keep the name).
- The opacity transition must be applied via inline style (not Tailwind), because Tailwind cannot interpolate the `2s linear` duration dynamically. Apply the transition only when isHolding is true to avoid the snap-back being animated: `style={{ touchAction: "manipulation", ...(isHolding ? { opacity: 0, transition: "opacity 2s linear" } : { opacity: 1 }) }}`.
- The existing `[@media(pointer:coarse)]:` Tailwind variants on className can stay for background-color classes; strip only the holding/armed background color transition classes that referenced the old mechanic (the `[@media(pointer:coarse)]:[transition:background-color_1s_linear]` and `!bg-destructive` classes).
