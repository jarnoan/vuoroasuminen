# Quick Task 260412-u66: Fix Sign-In Button Compatibility with Next.js

**One-liner:** Moved sign-in trigger from inline Server Action form to a Client Component using `signIn` from `next-auth/react` to fix the "unexpected response from server" error caused by next-auth@beta + Next.js redirect handling incompatibility.

## What Was Done

**Root cause:** `next-auth@beta.30` + Next.js has a compatibility issue where calling `signIn()` inside a Server Action (inline `"use server"` form action) causes an "unexpected response was received from the server" error. The server-side `signIn` issues a redirect response that the fetch-based Server Action transport cannot handle correctly.

**Fix:** Created `src/components/sign-in-button.tsx` as a `"use client"` component that calls `signIn("google", { redirectTo: "/dashboard" })` from `next-auth/react`. This is the client-side signIn which performs a proper browser redirect rather than going through Server Action transport. Updated `src/app/page.tsx` to import and render `<SignInButton />` instead of the inline form.
