## Component Inventory

Components needed for this phase, by surface:

### Sign-in Page (`/`)
- **No new components.** Replace `signIn("google")` (next-auth) call with Supabase OAuth trigger inside the existing `<SignInButton>` component. Visual output is identical: `<Button size="lg">Kirjaudu sisään Googlella</Button>`.

### Token Error Page (`/auth/error`) — NEW
- Centered layout matching sign-in page: `flex min-h-screen items-center justify-center`.
- `<h1>` with heading typography (text-4xl font-bold): no title text needed — page is self-explanatory from body copy.
- Body paragraph (text-base, muted-foreground): Finnish error explanation.
- `<Button size="lg">Kirjaudu sisään uudelleen</Button>`: primary accent fill, triggers new OAuth flow.
- No shadcn Alert needed — the error state is the entire page.

### Dashboard Warning Banner (`/dashboard`) — NEW
- Rendered inside `<DashboardShell>` above `<ViewToolbar>`, below `<header>`.
- Dismissible with an X icon button (`lucide-react` `X` icon, `aria-label="Sulje ilmoitus"`).
- Dismiss is in-memory only (no localStorage); banner reappears on next page load until owner token row exists.
- Uses shadcn `Alert` component variant `default` (not `destructive`). Finnish copy — see Copywriting Contract below.
- CTA inside banner: `<Button variant="link" size="sm">Kirjaudu sisään</Button>` — triggers Supabase OAuth sign-in.
- Component name: `OwnerWarningBanner` — accepts `onDismiss: () => void` prop.

### Header (`src/components/layout/header.tsx`) — REFACTOR (no visual change)
- Replace `import { auth } from "@/auth"` with Supabase `getUser()` equivalent.
- Replace `signOutAction` (Auth.js Server Action) with Supabase `signOut()` equivalent.
- Visual output of header is unchanged: app name, avatar, user name, sign-out button.

## Interaction Contracts

### OAuth Sign-In Flow
1. User clicks "Kirjaudu sisään Googlella" on sign-in page.
2. Browser redirects to Supabase OAuth endpoint with `prompt=consent&access_type=offline`.
3. After Google consent, Supabase redirects to `/auth/callback`.
4. Callback route exchanges code for session (`exchangeCodeForSession`), captures `provider_refresh_token`.
5. Success: redirect to `/dashboard`.
6. Failure (no refresh_token): redirect to `/auth/error`.

### Warning Banner Dismiss
1. Banner renders in `DashboardShell` when `showOwnerWarning === true`.
2. User clicks X button.
3. Local React state flips `dismissed = true`; banner unmounts.
4. On next full page load, server re-checks `user_google_tokens`; if still absent, banner renders again.

### Middleware Route Protection
- Unauthenticated requests to `/dashboard` redirect to `/` (sign-in page).
- Auth callback at `/auth/callback` and error page at `/auth/error` are public routes (no auth required by middleware).
