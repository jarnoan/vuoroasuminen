**Run the schema push:**

```bash
npm run db:push
```

This runs `npx drizzle-kit push` which:
- Reads the Drizzle schema (`src/db/schema/*.ts` via the project's `drizzle.config.ts`).
- Diffs against the live database referenced by `DATABASE_URL`.
- Applies the diff (only an additive `CREATE TABLE "user_google_tokens" (...)` for this plan).

`drizzle-kit push` is non-interactive by default for additive changes; no `--yes` flag is needed. If the command prompts (which it should NOT for a pure new table), capture the prompt text in your summary and stop — that means another change snuck in.

**Post-push verification:**

After the command exits with code 0, verify the table exists in the live database:

```bash
npx drizzle-kit introspect 2>&1 | grep -i "user_google_tokens" || echo "introspect did not find table"
```

Or, if `drizzle-kit introspect` is awkward, query directly via `psql` or `node -e`:

```bash
node -e "
const { Pool } = require('pg');
const p = new Pool({ connectionString: process.env.DATABASE_URL, ssl: { rejectUnauthorized: false } });
p.query(\"SELECT column_name, data_type, is_nullable FROM information_schema.columns WHERE table_name = 'user_google_tokens' ORDER BY ordinal_position\")
 .then(r => { console.log(JSON.stringify(r.rows)); return p.end(); })
 .catch(e => { console.error(e.message); process.exit(1); });
" 2>&1
```
