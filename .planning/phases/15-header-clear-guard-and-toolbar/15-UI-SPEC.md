## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), × button inset (`top-0.5 right-0.5`) |
| sm | 8px | Toolbar gap between controls (`gap-2`), panel internal gaps |
| md | 16px | Toolbar horizontal padding (`px-4`), panel horizontal padding |
| lg | 24px | Section padding (`px-6` desktop header) |
| xl | 32px | — |
| 2xl | 48px | — |
| 3xl | 64px | — |

Exceptions:
- Header padding collapses on mobile: `px-3 py-3` (mobile) → `sm:px-6 sm:py-4` (desktop). Source: CONTEXT.md D-10.
- Touch target minimum 44px height for all interactive elements on mobile (accessibility standard). The × clear button is 20×20px (`h-5 w-5`) — it is only visible after deliberate long-press arm, so this exception is acceptable; the primary cell button is `min-h-[40px]` and tappable at that size.
- Native `<input type="date">` visual height: `py-1` (4px top/bottom) + border = ~34px rendered. Acceptable because it inherits the OS date picker chrome on mobile.

## Interaction Contracts

### Clear Guard (MOB-02)

**Desktop (unchanged):**
- Hover on `ScheduleCell` outer `div.group` → × button becomes visible via `group-hover:opacity-100`
- Single click on × → fires `onClear(entryId)` immediately
- No long-press, no armed state

**Mobile (new):**
- Long-press (>1000ms) on the custody cell button → arms the × button (JS sets `isArmed = true`)
- × button transitions from `hidden` (not rendered or `opacity-0`) to visible when `isArmed`
- Armed state auto-disarms after 2000ms timeout
- Short tap on the armed × → fires `onClear(entryId)` and disarms
- Any other tap before 2000ms → armed state cancels (standard timeout; no separate global listener needed)
- Long-press detection: `pointerdown` → start 1000ms `setTimeout` stored in `useRef`. Cancel timer on `pointerup`, `pointercancel`, or `pointermove` beyond a small threshold (approx 8px) to avoid interference with scroll. Source: CONTEXT.md D-01 through D-06, specifics section.
- `touch-action: manipulation` on the cell button (or in `globals.css`) to eliminate 300ms tap delay on iOS

### Header (MOB-04)

| Element | Mobile (`< sm`) | Desktop (`sm:`) |
|---------|----------------|-----------------|
| "Vuoroasuminen" title | `hidden` | `block` |
| User full name | `hidden` | `inline` |
| Avatar Image or fallback | visible (`w-8 h-8`) | visible (`w-8 h-8`) |
| Sign-out button text | hidden; icon-only `<LogOut>` | "Kirjaudu ulos" text |
| Header padding | `px-3 py-3` | `sm:px-6 sm:py-4` |

Sign-out button on mobile: `aria-label="Kirjaudu ulos"` required (icon-only, no visible text). Source: CONTEXT.md D-07, D-08, D-09, D-10.

Avatar fallback (when `avatar_url` is null): first character of display name in colored circle. Use `bg-primary text-primary-foreground rounded-full w-8 h-8 flex items-center justify-center text-sm font-medium select-none`. Source: CONTEXT.md D-09.

### ViewToolbar (MOB-03, MOB-03a)

Container: `@container` on outer `<div>`. Child breakpoints use `@sm:` prefix. Source: CONTEXT.md D-16.

| Control | Below `@sm` | At `@sm` and above |
|---------|-------------|---------------------|
| "Prev week" button | `<ChevronLeft>` icon only, `aria-label="Edellinen viikko"` | "‹ Prev week" text |
| Date picker | Native `<input type="date">` (visible: `sm:hidden` CSS class strategy) | Calendar Popover (visible: `hidden sm:flex`) |
| "Tänään" button | Text "Tänään" visible | Text "Tänään" visible |

CSS toggle for date picker: render both `<input type="date">` and the Calendar Popover. Native input: `sm:hidden`. Popover: `hidden sm:flex` (or `hidden sm:block`). No `useMediaQuery` — avoids hydration flash. Source: CONTEXT.md D-12, D-14.

Native date input `onChange`: calls `handleDateSelect` (already exists). `value` attribute: `format(selectedDate, "yyyy-MM-dd")` when date selected, `""` otherwise. Source: CONTEXT.md D-13.

`flex-wrap` on toolbar row as overflow fallback. Source: CONTEXT.md D-20.

### ClearPanel (MOB-03)

Both "Alkaen:" and "Päättyy:" date pickers get the same CSS toggle treatment:
- `<input type="date">` visible on mobile (`sm:hidden`), wired to `setPickedStart` / `setPickedEnd`
- Calendar Popover hidden on mobile (`hidden sm:flex`), unchanged on desktop
- Labels "Alkaen:" and "Päättyy:" remain in both layouts. Source: CONTEXT.md D-11, D-12, D-13, D-15.

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Icon-only buttons must have `aria-label` | `LogOut`: `aria-label="Kirjaudu ulos"`. `ChevronLeft`: `aria-label="Edellinen viikko"`. Armed ×: `aria-label="Tyhjennä"` (already present). |
| Armed × must be keyboard-accessible | × receives `focus:opacity-100 focus-visible:opacity-100` — keyboard users can Tab to it and press Enter/Space. Desktop hover unchanged. Mobile armed state exposed via JS (not CSS-only). |
| Long-press must not block scroll | Cancel long-press timer on `pointermove` beyond 8px threshold; do not call `preventDefault()` on `pointerdown`. |
| Native date input | OS-native; inherits system accessibility. `aria-label` if no visible `<label>` is adjacent. In ViewToolbar (no label): add `aria-label="Valitse aloituspäivä"`. In ClearPanel: labels "Alkaen:" / "Päättyy:" are visible text, wire with `htmlFor` or wrap in `<label>`. |
| Avatar image alt text | `alt={fullName}`. Fallback div: `aria-hidden="true"` (decorative, name readable elsewhere) or `aria-label={fullName}` if it is the only name display on mobile. On mobile the name is hidden — use `aria-label={fullName}` on the fallback div. |
