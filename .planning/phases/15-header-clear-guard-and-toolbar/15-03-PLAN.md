|----------|-------------|
| User → native date input value | `e.target.value` is a string in "yyyy-MM-dd" format from the browser's date input; malformed values produce Invalid Date from parseISO |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-05 | Tampering | parseISO(e.target.value) | mitigate | Guard with `if (!e.target.value) return` before calling parseISO; navigateTo/setPickedStart/setPickedEnd receive a Date object which is then re-formatted by date-fns before any server call |
| T-15-06 | Information Disclosure | native date input value attribute | accept | Value is the user's own selected date, already shown in the Calendar Popover; no new disclosure |
</threat_model>
