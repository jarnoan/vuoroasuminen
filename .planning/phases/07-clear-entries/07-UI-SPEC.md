## Interaction Contracts

### Single Cell Clear (CLEAR-01)

**Assigned cell — hover/focus state:**
```
[ Isa  × ]
```
- The cell `<button>` renders the parent name on the left.
- An `×` `<button>` (aria-label="Tyhjennä") appears in the top-right corner on hover (`group-hover:opacity-100`) and on keyboard focus (`focus-within:opacity-100`), starting at `opacity-0`.
- Clicking the cell body calls `onToggle` (existing behavior unchanged).
- Clicking `×` calls `onClear` — no confirmation prompt. Clear is immediate.
- `×` button: `absolute top-0.5 right-0.5`, size `h-5 w-5`, `rounded-sm`, `text-xs`, `opacity-0 group-hover:opacity-100 focus:opacity-100 transition-opacity`.
- Cell wrapper: add `relative group` to enable the hover group context.

**Unassigned cell — clickable state:**
```
[ — ]  ← clicking assigns to father
```
- Currently renders inert `<span>—</span>`. In this phase it becomes a `<button>` styled as `w-full h-full min-h-[40px] rounded-md text-sm text-muted-foreground bg-muted/30 hover:bg-muted transition-colors`.
- Clicking calls `onAssignEmpty(childId, day)` → creates new entry assigned to father.
- No × button on unassigned cells.

### Bulk Clear Panel (CLEAR-02)

**Collapsed trigger:**
```
[ × Tyhjennä päiväväli ]
```
- `Button variant="outline" size="sm" className="font-semibold"`
- Placed in `<div className="px-4 pb-4">` directly below `<ExtendPanel>` in `<main>`.

**Expanded panel:**
```
┌──────────────────────────────────────┐
│  Alkaen: [ ma 12.5.2026 📅 ]          │
│  Päättyy: [ su 31.8.2026 📅 ]          │
│                                      │
│  Tyhjennetään: 112 päivää (2 lasta)   │
│                                      │
│  [ Vahvista ]  [ Peruuta ]            │
│                                      │
│  [error message if any]              │
└──────────────────────────────────────┘
```
- Panel: `<div className="border rounded-lg p-3 bg-muted/30 text-sm space-y-3">` — identical structure to ExtendPanel expanded state.
- Start date picker: Popover + Calendar (single mode), Finnish locale, defaults to today.
- End date picker: Popover + Calendar (single mode), Finnish locale, must be ≥ start date.
- Preview line: `aria-live="polite"` paragraph, visible only when both dates selected. Format: `Tyhjennetään: N päivää (M lasta)` where N = calendar days in range, M = child count from app config.
- Vahvista: `Button variant="default" size="sm" className="font-semibold"`, disabled while `isPending` or while either date is unset. In-flight label: `"Tyhjennetään..."`.
- Peruuta: `Button variant="outline" size="sm" className="font-semibold"`, disabled while `isPending`.
- After confirm success: panel collapses back to trigger button. No URL navigation.
- Error: `<p className="text-sm text-destructive" role="alert">` — same pattern as ExtendPanel.

### Loading / Pending States

| Action | Pending visual |
|--------|----------------|
| `clearCell` Server Action | Optimistic: cell immediately shows `—` (unassigned). No spinner on single cell. Re-sync from server on error (restore prior state). |

## Accessibility Requirements

- The `×` clear button must have `aria-label="Tyhjennä"` since it has no visible text.
- The unassigned `<button>` must have `aria-label="Lisää merkintä — {childName} {dayLabel}"` to distinguish cells.
- The preview `<p>` in ClearPanel must have `aria-live="polite"` so screen reader announces day count as dates change.
- The error `<p>` must have `role="alert"` for immediate announcement.
- Keyboard: `×` button reachable via Tab (it is a real `<button>`, not a pseudo-element).
- Focus management after bulk clear confirm: focus returns to the bulk clear trigger button.
