## Interaction Contract

### Trigger button state machine

| State | Visual |
|-------|--------|
| Collapsed | `[ + Lisää viikkoja ]` button visible below table |
| Expanded | Panel visible; trigger button hidden (or replaced by panel) |
| Pending (Server Action in flight) | Vahvista button disabled (`disabled`), shows "Lisätään..." label; Peruuta button disabled |
| Success | Panel collapses; `router.replace('?viewStart=<new-start>')` fires |
| Error | Panel stays open; error message appears below action row |

### Week count mode (default, D-05)

- Number input pre-filled with `12`.
- On change: recompute `endDate = addWeeks(scheduleEndDate, n)`, snap to end of that week (Sunday), update date preview label live.
- Label: `Lisätään: [12] viikkoa` where `[12]` is the `<input>`.
- Minimum: 1 week. Maximum: 52 weeks. Values outside range clamped by `min`/`max` attributes.

### Date picker mode (D-06, D-07)

- Activated by clicking `tai valitse päättymispäivä →` toggle link.
- Shows: `Päättyy: [ su 31.8.2026 📅 ]`
- Calendar opens via `Popover`. On date select, snap selected date to Sunday of that week (`endOfWeek(date, { weekStartsOn: 1 })`).
- Date preview updates live after selection.
- Deactivated by clicking `tai määritä viikkoina ←` toggle link. Returns to week count mode with last valid `n` restored.

### Date preview (D-03, D-04)

- Format: `Ajanjakso: ma {d.M.} – su {d.M.yyyy}` using `date-fns` `format()` with `fi` locale.
- Start date: day after `scheduleEndDate` (always a Monday).
- End date: derived from input (Sunday). Updates on every change without a separate preview step.

### Confirm (D-03)

- Clicking "Vahvista" calls Server Action with `{ scheduleEndDate, weeksOrEndDate }`.
- While pending: Vahvista shows "Lisätään..." and is `disabled`. Peruuta is also `disabled`.
- On success: call `router.replace('?viewStart=<newRangeStart>')` — navigates to first newly added week (D-09).
- On error: display inline error message below action buttons (see Copywriting Contract).

### Cancel

- Clicking "Peruuta" collapses panel. No state changes to schedule data. No navigation.

## Accessibility Contract

- Trigger button has visible text label — no icon-only button.
- Number input has an associated visible `<label>` or aria-label: `aria-label="Viikkojen määrä"`.
- Date preview paragraph is live (`aria-live="polite"`) — updates read by screen readers when input changes.
- Vahvista disabled state conveys via `disabled` attribute (not just visual opacity).
- Calendar Popover: focus traps while open (Base UI default). Keyboard: Tab through inputs, Enter on Vahvista, Escape collapses panel.
- Toggle links are `<button>` elements (not `<a>`) — keyboard activatable with Enter/Space.
- Touch targets: `size="sm"` buttons are `h-7` (28px). Acceptable for v1.1 (mobile refinement deferred to ONBR-02).
